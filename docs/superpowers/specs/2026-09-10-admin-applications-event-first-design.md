# Admin 참가신청 — 대회 우선 IA

## Goal
마블런 / 버추얼런은 접수 기간·기념품·신청 유형이 다르다. 관리자는 **대회를 먼저 고른 뒤** 그 대회 신청만 본다.

## Flow
1. 사이드: `참가신청` → `신청자관리` (`/admin/applications`)
2. 대회 선택 → 신청 목록 (`/admin/applications/{marvel|virtual}`)

## Filters (목록)
| 필터 | 마블런 | 버추얼런 |
|------|--------|----------|
| 검색 | ✓ | ✓ |
| 유형 (전체/개인/단체) | ✓ | 개인만 (유형 필터 숨김 또는 개인 고정) |
| 차수 (1/2/3차) | ✗ | ✓ |
| 코스 | ✓ | ✗ (또는 거리 없으면 생략) |
| 상태 | ✓ | ✓ |

## Columns (공통 + 조건부)
- 공통: 유형, 주문번호, 이름(개인명/단체명), 연락처, 상태, 신청일시
- 마블런 개인: 코스, 성별, 티셔츠(기념품)
- 마블런 단체: 대표자, 대표 코스, 인원
- 버추얼: 차수, 기념품

## Out of scope
- 실 API 연동
- 상세/수정 화면
